# Thesis

## Central hypothesis

Can deterministic scientific computation + high-throughput typed semantic judgment from Jev + selective deep scientific reasoning search very large biological information spaces more effectively or more efficiently than deterministic analysis or expensive reasoning alone?

A second formulation is: can OncoJev improve scientifically useful discovery per unit compute, data transfer, wall-clock time, and expensive reasoning?

This is a hypothesis, not a premise the architecture is allowed to guarantee.

## Three-tier model

1. **Deterministic science** measures, calculates, filters, joins, estimates, validates, and constructs populations.
2. **Jev** makes bounded typed semantic judgments over scientifically sufficient projections.
3. **OncoX** performs selective open-ended interpretation, hypothesis generation, alternative explanations, and experiment reasoning.

## Falsification

The architecture must allow evidence that:

- deterministic methods are sufficient for a task;
- deterministic + OncoX is as good as deterministic + Jev + OncoX;
- Jev helps only narrowly;
- Jev increases cost without increasing scientific quality;
- semantic filtering reduces recall of novel useful candidates;
- a projection removes scientifically material information.

The mature comparison is:

```text
A = deterministic
B = deterministic + OncoX
C = deterministic + Jev + OncoX
```

The main question is whether C shifts the science-efficiency frontier, not whether C can be made to look best on one metric.
