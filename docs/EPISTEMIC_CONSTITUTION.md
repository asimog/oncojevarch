# Epistemic constitution

These are the current high-priority invariants. Change them only through an explicit architecture decision with compelling evidence.

1. `ScientificEvidence != JevDecision != Hypothesis != LiteratureContext != AgentReasoning`.
2. Missing is not zero and is not a biological negative unless a validated contract says otherwise.
3. Source failure is not a biological negative.
4. Acquisition complete is not equivalent to assay available.
5. Operational shard is not scientific population.
6. Case, sample, aliquot, and file identities are distinct.
7. Typed output is not scientific truth.
8. Confidence is not permission.
9. Green software tests are not scientific validation.
10. Engineering readiness is not scientific readiness.
11. Agent/session memory is not scientific memory.
12. Material post-result experiment changes create a new experiment identity.
13. Historical scientific state and capability versions used historically are immutable records.
14. Jev does not create measured evidence.
15. OncoX does not create measured evidence.
16. Deterministic code owns exact measurement, arithmetic, statistics, and evidence construction.
17. A generated capability cannot self-promote.
18. Synthetic success validates mechanics, not cancer discovery.
